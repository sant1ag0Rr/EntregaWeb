# FIFA World Culture Hub

FIFA World Culture Hub es una aplicacion fullstack que conecta informacion de paises, contexto futbolistico y un modulo de usuarios dentro de una arquitectura separada en frontend y backend. El frontend ofrece la experiencia visual de exploracion y consumo de datos, mientras que el backend expone la API que centraliza la logica y las respuestas para la aplicacion.

## Como correr la app

### 1. Levantar el backend

```bash
cd backend
npm install
npm run dev
```

Backend disponible en:

```text
http://localhost:4000/api
```

### 2. Levantar el frontend

```bash
cd frontend
npm install
npm run dev
```

Frontend disponible en:

```text
http://localhost:3000
```
